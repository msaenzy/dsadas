# Carpeta de Logotipos y Favicons Institucionales

En esta carpeta `public/favicons/` puedes colocar y reemplazar tus archivos de imagen institucionales para que se muestren en tu sitio web y en la pestaña del navegador.

### Archivos recomendados en esta carpeta:

1. **`favicon.ico`**: Icono clásico de la pestaña del navegador.
2. **`favicon.svg`**: Icono vectorial moderno para pantallas de alta resolución.
3. **`apple-touch-icon.png`**: Icono de alta calidad para cuando los usuarios guardan la página en iOS / Android.
4. **`logo.svg`**: Logo principal vectorial de Spondylus Soluciones Digitales.

### Instrucciones para reemplazar tus archivos en GitHub:
1. Sube tus propios archivos llamados `favicon.ico`, `favicon.svg` y `apple-touch-icon.png` directamente a las carpetas `public/favicons/` y `public/` en tu repositorio de GitHub.
2. Haz commit de las imágenes.
3. Al refrescar tu página web en el navegador, verás tu favicon institucional oficial inmediatamente.
